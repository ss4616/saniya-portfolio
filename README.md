# Saniya Saad — Portfolio

A responsive personal portfolio focused on QA engineering, product quality, and project ownership.

## Publish on GitHub Pages

In this repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, and click **Save**.

Expected address after GitHub finishes publishing: https://ss4616.github.io/saniya-portfolio/

## Editing

- `index.html`: profile, project notes, tools, and contact links.
- `style.css`: colors, layout, typography, responsive and print styling.
- `script.js`: the print-to-PDF interaction.

Edits committed to main will publish automatically once Pages is enabled. No package installation or build command is needed.

## Content

Project narratives describe contributions and working methods; they do not claim unverified impact metrics, employment dates, certifications, or a formal project-lead title. The portfolio print button uses the browser’s Save as PDF option. It is not a downloadable resume.

Fonts load from Google Fonts with local system fallbacks. All navigation and local assets use relative paths compatible with GitHub Pages project sites.

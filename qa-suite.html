From draft to evidence

  1. Design. Add cases here, then export your draft.
  2. Commit. Replace cases.json in your repository. The workflow reads committed cases, not private browser drafts.
  3. Execute. A push to main starts the suite, or the repository owner can run it from the Actions page.
  4. Review. After Pages publishes, refresh this page to see statuses, durations, and the full report.

First-time setup: upload the included workflow and set GitHub Pages → Source to GitHub Actions. No passwords or access tokens are entered on this page.
